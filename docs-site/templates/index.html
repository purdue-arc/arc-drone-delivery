How this site stays honest

The Logbook and the status grid above are parsed directly out of CHANGELOG.md — add an entry there and both update on the next build, automatically. The Stack Reference and the Readiness Review's findings live in docs-site/data/*.yaml, because "what does this component do" and "is this safe to fly" take a person's judgment, not a regex. Either way, a push to the repo is what rebuilds the site — see docs-site/README.md for the full mechanics.
